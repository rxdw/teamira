# Bunny collection system

Как устроена система "зайцев" (companions) в Seenly, и как добавить новый
уровень зайца, когда у тебя будет готова новая картинка.

## Идея

- У каждого зайца есть уровень разблокировки: сейчас заяц с попкорном —
  уровень 1, заяц-критик — уровень 5. Дальше будет 10, 15 и т.д.
- Уровень пользователя считается на бэкенде из реальной активности
  (просмотры, отзывы, повторы, жанры, стрик, приглашения — см.
  `backend/app/routers/profile.py::_compute_level`). Это НЕ отдельная
  система для зайцев — те же цифры, что в профиле на кольце уровня.
- Как только пользователь достиг нужного уровня, заяц навсегда
  появляется в его коллекции (даже если потом активность упадёт —
  разблокировки не отбираются).
- В профиле есть секция «your bunny collection» — там показаны все
  зайцы: разблокированные — с именем и картинкой, ещё не открытые — как
  силуэт с замком и подписью "level N". Нажатие на разблокированного
  зайца делает его "любимым" (choice сохраняется на устройстве,
  `BunnyCollectionService`).
- Выбранный заяц — это тот, кто показывается ВЕЗДЕ по всему приложению
  (экран благодарности после логирования, экран приветствия при входе,
  онбординг, лоадеры, пустые состояния, ачивки и т.д.) вместо одной
  фиксированной картинки. Если пользователь ничего не выбирал — по
  умолчанию показывается заяц текущего уровня (т.е. поведение как
  раньше).

## Файлы, которые всё это реализуют

| Файл | Что делает |
|---|---|
| `mobile/lib/models/bunny.dart` | **Единственное место**, куда нужно добавлять нового зайца. Список `kBunnies` + вспомогательные функции (`bunniesUnlockedAt`, `currentTierBunny`, `bunnyById`). |
| `mobile/lib/services/bunny_collection_service.dart` | Хранит выбор пользователя (SharedPreferences, только на устройстве). `activeBunny(level)` — какого зайца рисовать прямо сейчас. |
| `mobile/lib/widgets/level_mascot.dart` | Заяц конкретного уровня (используется в профиле — кольцо уровня и список уровней). Всегда рисует зайца именно того уровня, который ему передали, а не выбор пользователя. |
| `mobile/lib/widgets/rabbit_mascot.dart` | Заяц-компаньон с настроениями (content/sad/celebrating/loading) — рисует **выбранного** зайца пользователя. Используется на экране благодарности, экране приветствия, онбординге, ачивках, лоадерах и т.д. |
| `mobile/lib/widgets/bunny_collection_row.dart` | Горизонтальная лента коллекции в профиле — разблокированные + запертые зайцы, тап = выбрать. Также умеет режим только для просмотра (`readOnly: true`) — см. ниже. |
| `mobile/lib/state/app_state.dart` | Кэширует текущий уровень пользователя (`cachedLevel`), чтобы виджеты не дёргали сеть на каждый показ зайца. Обновляется при входе в приложение и сразу после сохранения записи в дневник (момент, когда чаще всего происходит level-up). |

## На чужом профиле (профиль друга)

`mobile/lib/screens/friends/friend_profile_screen.dart` тоже показывает
коллекцию зайцев — но в режиме `BunnyCollectionRow(level: ..., readOnly:
true)`. Разница с собственным профилем:

- Нельзя тапнуть и выбрать зайца — это не твой профиль.
- Подсвечивается не "любимый" заяц (это личный выбор человека, хранится
  только у него на устройстве, не синхронизируется — узнать его с
  чужого телефона невозможно в принципе), а заяц **текущего уровня**
  этого человека — то есть "докуда он дошёл", помечено бейджем
  "current".

Уровень друга уже приходит с бэкенда в `FriendProfile.level` (см.
`backend/app/routers/friends.py::get_friend_profile`) — ничего
дополнительного получать не нужно.

## Как добавить нового зайца (например, уровень 10)

1. Пришли мне картинки (обычную + для тёмной темы), либо сразу положи
   их в `mobile/assets/mascot/`. Технические требования к артам:
   - Холст **742×1153px**, PNG с прозрачным фоном — как у существующих
     `bunny_with_popcorn_level1.png` / `bunny_critic_level5.png`.
   - Сам рисунок зайца по центру холста, занимает примерно 65% ширины
     и 78% высоты (вокруг — прозрачные поля) — так же, как у текущих
     двух. Это нужно, чтобы кроп в виджетах (`_cropScale` /
     `cropScale`) увеличивал зайца одинаково для всех уровней без
     ручной подгонки под каждую картинку.
   - Два файла на уровень: обычный (`bunny_<name>_level<N>.png`) и
     версия для тёмной темы (`bunnyDark_<name>_level<N>.png`).
2. В `mobile/lib/models/bunny.dart` добавь новую запись в `kBunnies`
   (список отсортирован по возрастанию `unlockLevel`):

   ```dart
   Bunny(
     id: 'director',                // стабильный id, не меняется потом
     unlockLevel: 10,
     name: 'director bunny',        // как покажется в коллекции
     lightAsset: 'assets/mascot/bunny_director_level10.png',
     darkAsset: 'assets/mascot/bunnyDark_director_level10.png',
   ),
   ```

3. Всё. Ничего больше менять не нужно — так как:
   - `pubspec.yaml` уже включает всю папку `assets/mascot/` целиком,
     новый файл подхватится автоматически.
   - Профильная коллекция, список уровней ("coming soon" / "unlocked"),
     `LevelMascot` и `RabbitMascot` читают список зайцев из
     `kBunnies` — новый уровень появится везде сам.

Просто пришли мне готовые картинки (или сразу файл), скажи "добавь
зайца на уровень N" — и я добавлю запись сам.
