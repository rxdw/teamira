# Альбом пары (премиум) — записки, капсулы, годовщина

Живёт на экране совместного просмотра, вкладка «мы»: карточка «альбом пары» → три двери
(общая книга, капсулы времени, наша годовщина). Только для пары из двух человек;
компания из 3+ альбома не видит.

## Логика (то, ради чего всё устроено)

**Записки**
- Пишутся ДО вечера: из шита планирования (последний шаг, до «ticket») или с плитки
  «запланировано» (конвертик слева внизу). У каждого своя записка, одна на человека на просмотр.
- Привязаны к фильму (связка + источник + id), а не к запланированной карточке: можно писать
  до планирования, удаление карточки не уничтожает слова, повторный просмотр начинает новый «раунд».
- Сервер НИКОГДА не отдаёт чужой текст, пока вечер не отмечен просмотренным — только факт «записка есть».
- «Просмотрено» (в одной транзакции с раскрытием, под блокировкой строки) открывает записки
  обоим и замораживает их. Партнёру остаётся ответить одним эмодзи.
- Церемония раскрытия проигрывается один раз на человека (флаг opened_at на сервере).
- Писать нельзя на уже просмотренный вечер (409).

**Капсулы**
- Создатель выбирает дату (30 дней … 10 лет) и сразу запечатывает своё письмо; дата не меняется.
- Партнёр может добавить письмо до открытия. Письма неизменяемы, читать их до даты не может никто.
- «Открыта или нет» решает серверная дата UTC (не часы телефона).
- До 3 запечатанных капсул одновременно; создатель может убрать капсулу, пока в ней нет письма партнёра.

**Годовщина**
- Дата «мы вместе» — календарный день, задаёт любой из двоих (последняя запись побеждает,
  второму видно «дату указал(а) …»). Считается по календарю (29 февраля → 28-го), вехи 100/200/300/…
- Конфетти один раз в сам день годовщины / круглой даты.

**Премиум и бесплатная часть**
- Бесплатной паре достаётся «пробная порция», чтобы привычка писать записки успела сложиться:
  **3 записки на каждого** (`FREE_NOTES_PER_AUTHOR`) и **1 капсула на пару** (`FREE_CAPSULES_PER_LINK`).
  Безлимит записок и капсул — с премиумом у любого из двоих (то же правило, что у очереди совместного просмотра).
- Записки считаются по человеку и по тому, что существует сейчас: забранная запечатанная записка
  возвращает слот, раскрытая остаётся в книге и слот не возвращает. Переписать уже оставленную записку
  слот не тратит — только создание новой.
- Капсулы считаются по паре, открытые тоже (иначе лимит превратился бы в «одна бесплатная в месяц»
  навсегда). Забранная капсула возвращает слот.
- Письмо партнёра в уже существующую капсулу не закрыто никогда: капсула — обещание на двоих.
- Годовщина (дата «мы вместе») осталась только для премиума.
- Превышение → 402; клиент показывает апселл пары с текстом под ситуацию (записки / капсула / годовщина).
- ЧИТАТЬ — всегда, даже после окончания подписки: воспоминания и капсулу в заложники не берём.
- `GET /partner/album` вместо `can_write` отдаёт `is_premium`, `notes_limit/notes_used`,
  `capsules_limit/capsules_used` (null-лимит = без потолка); клиент ничего не хардкодит.

**Разрыв связи** удаляет альбом у обоих (каскад); диалог разрыва предупреждает об этом,
если в альбоме что-то есть.

## Бэкенд
- models.py: PairAlbumSettings, PairNote, PairCapsule, PairCapsuleLetter, PairCapsuleRead
- migrations/versions/c4d1e7a92b38_pair_album.py (создаёт таблицы, только если их ещё нет)
- app/pair_album.py — правила и чистая арифметика дат; routers/pair_album.py — API `/partner/album/*`
- partner.py: раскрытие записок внутри «watched» (+ блокировка строки), `album_reveal_count` в ответе
- push.py: категория «Наш альбом» + 4 уведомления (тексты не раскрывают содержимое записок)
- scripts/send_scheduled_push.py: годовщина, круглая дата, «капсула ждёт вас» (раз в день на человека)
- tests/test_pair_album.py — 35 тестов

## Приложение (Flutter)
- lib/screens/partner/album/: главная альбома, книга, капсулы, годовщина, шиты записки/капсулы,
  церемонии раскрытия записки и открытия капсулы, общие виджеты (конверт, воск, бумага, конфетти, искры)
- lib/models/pair_album.dart, lib/services/pair_album_service.dart, lib/utils/album_dates.dart
- Подключено: co_view_hub_screen.dart (карточка на «мы», конвертик на плитках, раскрытие после
  «смотрю», предупреждение при разрыве), plan_evening_sheet.dart (строка «записка для …»),
  evening_plan_card.dart (раскрытие после двух кнопок «просмотрено»), push_notification_manager.dart
  (тапы по пушам альбома), api_client.dart (put), co_view_entry.dart (albumRevealCount),
  push_service.dart (категория)
- Анимации уважают «уменьшить движение» в системе (церемонии прыгают к финальному кадру).
- Строки альбома лежат в screens/partner/album/album_strings.dart (`at(ru, en)`), а не в ARB:
  app_translations.dart генерируется, а инструментов для регенерации в момент работы не было.

## Проверено / не проверено
- Бэкенд: весь набор — 792 теста проходят. Два теста падают и на исходном проекте без моих
  правок (test_push_triggers_diary::TestLevelUpPush::…crossing_a_level_threshold,
  test_recommendations::…stakes_points_and_debits_the_staker) — к альбому не относятся.
- Flutter: код НЕ компилировался (в среде нет Flutter SDK). Нужно запустить
  `flutter analyze` и `flutter test test/utils/album_dates_test.dart`, затем пройти вручную:
  записка → «просмотрено» → раскрытие; капсула → открытие (сдвинуть дату на сервере);
  годовщина; апселл без премиума; разрыв связи.
