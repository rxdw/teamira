# Кинопоиск: оценки и отзывы для русскоязычных пользователей

Для `lang=ru` (переключатель «язык контента» в приложении) на экране тайтла появляются оценки Кинопоиска и IMDb, а в листе отзывов — рецензии Кинопоиска и фильтр по источникам. Для `en` ничего не меняется и запросов к Кинопоиску нет.

Источник — ПоискКино (`api.poiskkino.dev`, v1.5). Это неофициальный посредник, не API Яндекса, поэтому всё построено так, чтобы его отсутствие ничего не ломало.

## Что видит пользователь

- Блок оценок: рядом с TMDB — «кинопоиск» и «imdb» (оценка и число голосов).
- Лист отзывов: ряд чипов «все · Кинопоиск · Trakt · TMDB» с количеством (если источник один — чипов нет). Рецензии Кинопоиска идут первыми.
- Карточка рецензии Кинопоиска: заголовок, тональность лентой (`tapeSage` / `tapeRose` / `tapeMustard`), оценка автора (только если он её поставил), лайки, ссылка «читать полностью на Кинопоиске».
- Счётчик «N рецензий» включает рецензии Кинопоиска, чтобы совпадать со списком.

## Бэкенд

- `adapters/poiskkino.py` — HTTP, разбор, ранжирование (лайки минус дизлайки), обрезка до 1500 символов по абзацу/предложению/слову.
- `kinopoisk.py` — кэш: найден или «нет на Кинопоиске» → кэшируется, срок зависит от возраста тайтла:

  | Тайтл | Оценки + сопоставление | Отзывы |
  |---|---|---|
  | вышел меньше года назад | 21 день | 14 дней |
  | старше | 120 дней | 90 дней |
  | «нет на Кинопоиске» | 7 дней | — |

  API отдаёт только год выхода, поэтому дата принимается за 1 июля этого года (`is_recent`); неизвестный год считается свежим. Обновление ленивое: запись перекачивается только когда тайтл открыли после её протухания. **Сбой не кэшируется** (`KpUnavailable` пробрасывается через `cached_dynamic`, ничего не записывается), а если обновить не удалось — показывается предыдущая копия (`cache.get_dynamic_stale`), а не пустота.
- Лимиты: свой дневной бюджет `POISKKINO_DAILY_BUDGET` (180 из 200 бесплатных), пауза после ошибки (сеть/5xx — 2 мин, 429 — 15 мин, 401/403 — 1 час, с `logger.error`). Счётчик в памяти процесса, не в БД.
- Сопоставление по `externalId.tmdb`; TMDB нумерует фильмы и сериалы раздельно, поэтому выбирается документ с нужным `isSeries`.
- `GET /media/detail?lang=ru` и `GET /media/reviews?lang=ru`. Оценки Кинопоиска добавляются после чтения кэша (`_apply_kinopoisk`) и в вечный кэш деталей не попадают.
- Схемы: `RatingsOut` + `kp_rating/kp_votes/imdb_rating/imdb_votes`; `TmdbReviewOut` + `title/tone/likes`, `source` может быть `"kinopoisk"`.
- `tests/test_poiskkino.py`  — 30 тестов (разбор, ошибки и паузы, бюджет, сроки кэша, «сбой не кэшируется», показ старой копии, роутеры).

## Приложение

- `MediaRatings`, `TmdbReview` — новые поля; `MediaService.detail/reviews` передают `lang` (по умолчанию из `LocaleService.contentPrefersRussian`).
- `_RatingsRow` — две новые колонки; `reviews_sheet.dart` — `PillChip`-фильтр, `_ToneTag`, заголовок и лайки.
- Строки добавлены в `lib/l10n/app_en.arb` и `app_ru.arb` (источник правды) и в `app_translations.dart`; расхождение ARB и сгенерированного файла устранено, см. `CHANGES_l10n_reconciled.md`.

## Что нужно сделать руками

1. Добавить в `backend/.env`: `POISKKINO_API_KEY=<токен>` (пример в `env.example`), пересоздать контейнер: `docker compose up -d --force-recreate api`.
2. **Токен нельзя хранить в чатах и архивах** — тот, что уже был отправлен в переписку, лучше перевыпустить.
3. Доступность API: из России он открывался только с VPN. Бэкенд должен ходить к `api.poiskkino.dev` с машины, откуда он доступен. Проверка изнутри контейнера:
   `docker compose exec -T api python -c "import httpx,os; print(httpx.get('https://api.poiskkino.dev/v1.5/movie', params={'externalId.tmdb':'157336','limit':1}, headers={'X-API-KEY': os.environ['POISKKINO_API_KEY']}).status_code)"`
   Если не 200 — Docker не использует VPN хоста; тогда приложение просто не покажет Кинопоиск.

## Что не проверено вживую

- Ссылка «читать полностью» ведёт на `kinopoisk.ru/film|series/<id>/reviews/` (API не отдаёт ссылку на отдельную рецензию). Формат адреса стоит открыть руками.
- Flutter-часть не компилировалась (в среде нет Dart SDK) — перед сборкой нужен `flutter analyze`.
- Реальные ответы ПоискКино проверены по двум вашим запросам (Интерстеллар); сериалы и аниме не пробовались.
