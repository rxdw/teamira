# Книги: оценка Hardcover со ссылкой (без текста отзывов)

На экране книги в блоке оценок появляется «hardcover /5» (оценка 0–5 и число оценивших) и строка «отзывы на Hardcover ↗», которая открывает страницу книги на hardcover.app. Лист отзывов для книг не открывается.

## Почему без текста отзывов

Политика API Hardcover (docs.hardcover.app/api/getting-started, раздел «Commercial API Use») запрещает публичным и коммерческим продуктам использовать данные их пользователей: отзывы, оценки отдельных пользователей, списки. Агрегированные числа (средняя оценка, число читателей) разрешены, если указан Hardcover — поэтому подпись на экране «hardcover». Текст отзывов оттуда добавлять нельзя без повторного чтения этой политики. У Goodreads API закрыт, у LiveLib публичного API нет, у Open Library и Google Books только агрегаты.

## Как это работает

- Книги у вас из Google Books (`gbooks-<id>`), поэтому сначала берутся ISBN тома (`GoogleBooksAdapter.isbns`, один запрос, кэш на год), затем рейтинг по ISBN в Hardcover (GraphQL `editions(where: {isbn_13: {_eq: …}})`, сначала ISBN-13, потом ISBN-10).
- Кэш по тем же правилам, что у Кинопоиска: ответ (в том числе «нет на Hardcover») кэшируется — оценка 30 дней, «нет в Hardcover» 7 дней; **сбой не кэшируется**, при неудачном обновлении показывается предыдущая копия.
- Оценка добавляется после чтения кэша деталей (`_apply_hardcover`) и в вечный кэш не попадает. Для всех языков (книги не привязаны к `lang`).
- Лимиты: свой дневной бюджет `HARDCOVER_DAILY_BUDGET` (4000 из 5000), паузы после ошибок (сеть/5xx 2 мин, 429 по `Retry-After`, 401/403 и «запрос отклонён» 1 час). При 403 в лог пишется название недостающего scope (токен — никогда).

## Что общего вынесено

- `app/adapters/quota_guard.py` — дневной бюджет и пауза (раньше был внутри `poiskkino.py`).
- `app/source_cache.py` — «свежий кэш → запрос → предыдущая копия → None»; Кинопоиск и Hardcover используют один и тот же код.

## Что нужно сделать руками

1. Создать токен на hardcover.app/account/api и дать ему только нужные права на чтение (если не хватит, 403 в логе назовёт нужный scope).
2. Добавить в `backend/.env`: `HARDCOVER_API_TOKEN=…` (пример в `env.example`), `docker compose up -d --force-recreate api`.
3. Токены в чаты и архивы не класть.

## Что не проверено вживую

- Hardcover — бета-API («могут сломаться без предупреждения»). Форма запроса и ответа взята из их документации (поля `isbn_13`, `isbn_10`, `book.slug`, `rating`, `ratings_count`, `users_count`), живых ответов у меня нет. Когда будет токен, сделайте один запрос и сравните с `tests/test_hardcover.py`.
- Тесты написаны, но не запускались (`pytest tests/test_hardcover.py tests/test_poiskkino.py -q`), Flutter-часть не компилировалась (`flutter analyze`).
- Покрытие: книги без ISBN в Google Books и книги, которых нет на Hardcover, останутся без оценки — это нормально.
